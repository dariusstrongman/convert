request.sh 
# Generate a PDF from HTML
curl -X POST https://n8n.myaibuffet.com/webhook/pdfapi \
  -H "Content-Type: application/json" \
  -H "x-api-key: pk_your_api_key_here" \
  -d '{
    "html": "<h1>Hello World</h1><p>This is a PDF.</p>",
    "format": "Letter",
    "margin": { "top": 20, "right": 15, "bottom": 20, "left": 15 }
  }'

// api reference

Documentation

POST /webhook/pdfapi

Generate a PDF from HTML content.

Headers

HeaderValueRequired
Content-Typeapplication/jsonREQUIRED
x-api-keypk_your_keyREQUIRED

Body Parameters

ParamTypeDescription
htmlstringHTML content to convert. Max 500KB. REQUIRED
formatstringPage size: Letter, A4, Legal. Default: Letter
marginobject{"top": 20, "right": 15, "bottom": 20, "left": 15} in mm
landscapebooleanLandscape orientation. Default: false

Response

FieldTypeDescription
successbooleanWhether the PDF was generated
pdf_base64stringBase64-encoded PDF content
size_bytesintegerPDF file size in bytes
duration_msintegerGeneration time in milliseconds
usageobject{"used": 1, "limit": 50, "plan": "free"}

Error Codes

StatusMeaning
401Missing or invalid API key
400Missing html field or HTML exceeds 500KB
429Usage limit reached for your plan
500PDF generation failed (server error)
